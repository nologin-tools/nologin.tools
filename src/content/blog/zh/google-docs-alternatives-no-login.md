Google Docs 是一款优秀的文字处理工具。问题不在于产品本身，而在于挡在前面的那道门槛。要创建一个文档，你必须拥有 Google 账号。如果想与没有账号的人协作，事情很快就会变得繁琐复杂。而在借来的电脑、工作设备上，或者你只是不想让又一项服务与你的 Google 身份绑定时，你就会陷入两难。

替代方案并不是非得去安装 LibreOffice 或打开庞大的 Microsoft Word。现在的浏览器端工具让你几秒内就能开始打字——无需账号、无需登录，更没有冗长的注册表单挡路。其中一些支持多人实时协作，一些具备端到端加密，并且它们都能在现代浏览器中瞬间启动。

本文盘点了五款真正能满足不同写作需求的免登录工具。每款都有其鲜明的定位，而且没有任何一款会向你索取邮箱地址。

## 为什么"无需账号"比听起来更重要

账号要求并不仅仅是一点微小的不便。Google 的账号体系将你的文档与你的真实身份紧密绑定，这意味着你写下的每一个字都是你 Google 用户画像的一部分。如果你在同一个账号下混合处理工作文档、个人项目和敏感笔记，所有内容都处于可检索且直接归属于你的状态。

此外还有访问门槛问题。任何人都可以无需登录查看公开分享的 Google Doc，但你无法在免登录状态下创建新文档。这种单向不对称是刻意设计的——Google 的商业价值在于将已验证用户留存在其生态系统内，而不是方便人们免账号使用工具。

对于很多人来说这无所谓。但对另一些人——比如在公共电脑上工作、身处高隐私要求环境，或者只是想快速起草文字免除繁琐流程的人来说，这就是实实在在的阻碍。下面这些工具之所以存在，正是因为这道阻碍本就不该存在。

## Etherpad：零门槛多人实时协同写作

当两个或更多人需要共同写作又不想注册账号时，[Etherpad](https://etherpad.org/) 是最经典的原生答案。作为自 2008 年就开源的软件，全球有数十家机构运营着开放的公共实例，任何人都可以立即创建协作文档。

由 Riseup 运营的实例 [pad.riseup.net](https://pad.riseup.net/) 是最稳定可靠的公共服务之一；维基媒体基金会也在 etherpad.wikimedia.org 上维护着实例。打开页面，点击"创建新 Pad"，就能获得一个专属链接。把这个链接分享给任何人，大家就能立刻同时编辑文档——两端都不需要账号。

每位参与者的修改都会以专属颜色高亮显示，你也可以在不注册的情况下设置自己的昵称。页面底部的历史时间轴滑块支持回放文档的整个演变历程，对于复盘团队思路和内容协作极具价值。

格式排版保持了极简克制：粗体、斜体、下划线、删除线、有序和无序列表以及缩进。没有表格，没有图片插入，也没有内嵌表格。界面虽十五年未大改，但如果你的目标是快速协同记录会议纪要、头脑风暴或草拟文案，这些都不成问题。

实用细节提醒：公共实例上的协作文档不会永久保留。例如 Riseup 会清理连续 60 天无编辑的文档。如果内容重要，请及时导出——Etherpad 支持导出为纯文本、HTML 和 PDF 等格式。

## CryptPad：端到端加密的隐私富文本套件

[CryptPad](https://cryptpad.fr/) 就像是这样一个项目：有人想打造一款 Google Docs 替代品，同时反问"如果服务器本身根本无法读取你的文档呢？" 这绝非营销噱头，加密机制直接植根于其系统架构。所有内容在离开浏览器发送给 CryptPad 服务器前就已经完成客户端加密，这意味着即使是运维人员也无法获知你写了什么。

你完全可以匿名使用。访问 cryptpad.fr，创建一个富文本（Rich Text）文档即可直接动笔。在无账号模式下，你依然享有实时协作能力、完整的富文本排版（段落样式、表格、图片、批注评论、修改标记）以及分享链接。匿名创建的文档如果 90 天内无人访问会自动过期，但对于临时性工作流来说这已绰绰有余。

其富文本编辑器在功能深度上最为接近 Google Docs，提供层级标题、表格插入、内嵌图片与讨论串，协作时每个成员同样会分配专属色彩。

CryptPad 由法国巴黎的 XWiki SAS 团队开发，严格遵守欧盟 GDPR 法规。其零知识加密模型决定了你的数据无法被用于广告分析或用户画像——服务器拿到的只有密文数据块。

## StackEdit：专注 Markdown 的极简排版利器

如果你习惯或想尝试使用 Markdown 写作，[StackEdit](/tool/stackedit-io) 是目前浏览器中最清爽的编辑器之一。它完全无需登录，100% 在本地浏览器中执行，文档默认持久保存在浏览器的本地存储中。

界面采用经典的左右双栏布局：左侧编辑 Markdown 源码，右侧实时渲染预览。语法高亮让左侧源码一目了然，右侧排版即时联动。除了标准 Markdown，StackEdit 还原生支持表格、注脚、任务清单以及用于学术科技写作的 LaTeX 数学公式。

导出功能十分健全，包括 Markdown、HTML、带样式的排版 HTML 以及排版考究的 PDF。虽然它也支持可选绑定 GitHub 或 Google Drive，但这完全由你决定。对于单人离线起草博客文章、记录技术笔记或编写文档，StackEdit 的体验轻巧且毫无束缚。

## Dillinger：轻巧上手的在线 Markdown 工作台

[Dillinger](/tool/dillinger-io) 与 StackEdit 类似，但交互更加轻量直观。它是一款无需账号的浏览器 Markdown 编辑器，同样支持导出为排版精美的 HTML、原生 Markdown 和 PDF。

其 Styled HTML 导出功能尤为亮眼，生成的文档排版专业典雅，非常适合发给不熟悉 Markdown 语法的同事直接阅读。

需要注意的是：如果不主动导出或绑定第三方网盘，关闭标签页内容就会随之清空。但对于单次起草短文、整理技术 README 或是临时写一封长邮件而言，这种即开即用、用完即走的轻巧感正是其最大魅力。

## ZenPen：极简纯粹的沉浸空白画布

[ZenPen](/tool/zenpen-io) 将"极简"做到了纯粹的极致。它是一个纯粹的防打扰写作环境——全屏展开的一片干净白色空间，只有在选中文字时才会浮现微型工具栏，提供粗体、斜体、引用和超链接四项功能。

ZenPen 没有保存功能，不生成链接，也不向服务器同步任何数据。关掉标签页，文字就会消失（除非你已复制出来）。对于习惯了到处自动保存的人来说这可能有些不可思议，但用于专注构思、冲破写作瓶颈或起草一段长文时，没有任何标签、菜单和通知打扰的纯白界面能带来惊人的专注力。

## 核心特性横向对比

| 工具 | 多人实时协作 | 核心格式 | 导出能力 | 端到端加密 | 数据保留机制 |
|------|--------------|--------|--------|-----------|---------|
| Etherpad | 是 ✓ | 纯文本 + 基础样式 | TXT, HTML, PDF | 否 | ~60 天无访问清理 |
| CryptPad | 是 ✓ | 完整富文本 | Word, ODT, PDF | 是 ✓ | 匿名约 90 天 |
| StackEdit | 否 | Markdown + LaTeX | MD, HTML, PDF | 本地存储 | 浏览器 LocalStorage |
| Dillinger | 否 | Markdown | MD, HTML, PDF | 否 | 会话临时（关闭丢失） |
| ZenPen | 否 | 纯文本 | 无需导出（直接复制） | 否 | 会话临时（关闭丢失） |

根据使用场景各取所需：临时会议协同选 Etherpad；涉密团队文案选 CryptPad；个人博客草稿选 StackEdit；快速格式化导出选 Dillinger；摒除杂念深度构思选 ZenPen。

## 总结：告别强制注册

尝试这些工具只需在浏览器中打开即可验证。它们无需信用卡，无需免费试用期，更不会在日后向你推销订阅。需要时打开，用完关掉标签，数据自主掌控。
